Política de privacidade — Gestão Horário

A Gestão Horário é uma aplicação pessoal de gestão de horários e turnos, de uso privado do seu autor.

Dados usados

  • Conta Google: nome e email, para iniciar sessão.
  • Google Calendar (âmbito calendar.events): ler e escrever eventos do calendário principal, para manter a app e o Google Calendar sincronizados nos dois sentidos.

Onde ficam

Os dados ficam numa base de dados Supabase na União Europeia (Irlanda), acessível apenas pelo próprio utilizador (Row Level Security). O token de acesso ao Google é guardado cifrado e nunca é enviado para o browser.

Partilha

Os dados não são vendidos, partilhados com terceiros nem usados para publicidade. O uso de dados recebidos das APIs Google cumpre a Google API Services User Data Policy, incluindo os requisitos de Limited Use.

Apagar

Em Definições → "Desligar o Google" a ligação é removida. Pode também retirar o acesso em myaccount.google.com/permissions. Para apagar todos os dados, contacte o autor.
